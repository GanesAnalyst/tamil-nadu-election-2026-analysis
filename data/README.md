# Spatial Data

This folder contains the constituency boundary GeoJSON used for the Tamil Nadu Assembly Election 2026 Tableau map.

## File

`tamil_nadu.geojson`

The GeoJSON contains constituency-level polygon boundaries for Tamil Nadu Legislative Assembly constituencies.

## Source

The spatial data was obtained from the public GitHub repository:

`saisantoshv3/assemnbly_gis_files`

Path used:

`2026_assembly_election/tamil_nadu_S22/tamil_nadu.geojson`

The repository provides election-related GIS boundary files derived from Election Commission of India data.

## Usage

The GeoJSON was connected to Tableau and related to the election datasets using the Assembly Constituency number (`AC No` / `constituency_no`).

It was used to create the constituency-level electoral map in the final Tableau dashboard.
